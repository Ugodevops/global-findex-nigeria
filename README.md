# Global Findex Nigeria: Digital Technology and Financial Inclusion

## Project Overview

This project explores how access to and use of digital technology relate to people's access to and use of financial services in Nigeria, using data from the World Bank's Global Findex Database 2025.

The analysis examines patterns across demographic and geographic groups to understand how digital technology and financial inclusion intersect.

## Project Objective

To use data to understand how access to and use of digital technology relate to people's access to and use of financial services in Nigeria.

## Key Areas of Analysis

- Access to and use of financial accounts.
- Mobile money account ownership.
- Internet access and usage.
- Digital payments and merchant payments.
- Differences across gender, age groups, education levels and geographic locations.
- Relationships between digital technology usage and financial inclusion.

## Data Source

**World Bank – Global Findex Database 2025**

The database provides information on financial inclusion, digital payments, mobile money, internet usage and related indicators.

## Tools and Technologies

- **Microsoft Power BI:** Data visualization and interactive reporting.
- **Power Query:** Data preparation and transformation.
- **DAX:** Calculations and analytical measures, where applicable.

## Analytical Approach

The project uses descriptive and comparative analysis to identify patterns and differences across population groups.

Observed relationships are treated as associations, not proof of causation.

## Project Deliverable

The main deliverable is an interactive Power BI report (`Global_findex_Nigeria.pbix`) designed to communicate findings about digital technology and financial inclusion in Nigeria.

## Project Status

Power BI report developed and published to this GitHub repository.
